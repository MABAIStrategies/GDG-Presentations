🚀 GDG Presentations Hub
This web application serves as a central repository for Google Developer Group (GDG) presentations. It provides an organized, browser-based interface to navigate through different presentation modules and slide decks.

📂 Current Structure
The project is organized by individual presentation folders to keep assets and slides modular:

New folder: Contains the core logic for Presentation #1.

Static Hosting Ready: Optimized for deployment via GitHub Pages.

🛠️ Tech Stack
HTML5 & CSS3: For a clean, slide-deck style presentation layout.

Vanilla JavaScript: Handles navigation and interactive elements within the presentations.

🚀 How to View Locally
Clone the Repo:

Bash
git clone https://github.com/MABAIStrategies/GDG-Presentations.git
Open a Presentation:
Navigate into the specific presentation folder (e.g., New folder) and open the index.html file in your preferred browser.
